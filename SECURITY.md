# OMEGA ARCHITECTURE SECURITY PROTOCOL

## Overview
This repository utilizes the DARLEK CANN v3.0 evolution engine. Security is enforced via strict isolation of stateful AI artifacts.

## Data Governance
- **Quantum/State Persistence**: Files ending in `.consciousness.dump`, `.quantum.data`, or `.swarm.state` are strictly local to the runtime environment.
- **Self-Refactoring**: All evolution logs (`.evolution.history`) are excluded from VCS to prevent recursive commit pollution.
- **Secrets**: Managed via `.env.local` patterns. Never commit `.vault` or `.key` files.

## Compliance
This structure adheres to the `psr-governance` framework for self-modifying systems.
